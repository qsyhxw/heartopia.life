Search questions

Can I search a misspelling?

Yes. The finder checks partial names and common aliases. For example, Picaso also finds Picasso Bug.

Why does a result open a database list?

Not every entry has a separate guide yet. Those results open the right database with the name already filled in.

Is a login required?

No. Searching is available immediately and does not require an account.
