1

로그인 방식과 지역 기록

나중에 다시 사용할 로그인 방식과 선택한 지역을 기억해 두세요. 다른 계정으로 접속했을 때 기존 캐릭터가 보이지 않는 일을 줄일 수 있습니다.

2

튜토리얼과 기본 퀘스트 진행

처음부터 모든 수집을 시작하기보다 기본 이동, 도구, 가방, 지도 사용법을 먼저 익히세요.

3

좋아하는 취미 하나 선택

낚시, 요리, 원예, 곤충 채집, 새 관찰 중 하나를 먼저 익히고 필요한 위치와 조건을 도감에서 확인하세요.

4

쿠폰과 일일 할 일 확인

사용 가능한 교환 코드를 확인하고, 매일 반복할 항목은 Daily Tasks 도구에 체크해 두면 놓치기 쉽지 않습니다.

두근두근타운 초보 FAQ

두근두근타운과 Heartopia는 같은 게임인가요?

같은 게임입니다. 한국어 명칭은 두근두근타운, 글로벌 명칭은 Heartopia이며 두두타라는 줄임말도 사용됩니다.

무료로 플레이할 수 있나요?

공식 스토어에서 무료로 시작할 수 있으며 선택형 게임 내 구매가 포함됩니다.

한국어를 지원하나요?

한국 공식 사이트와 한국어 Steam 페이지가 제공되며 Steam에는 한국어 인터페이스 지원이 표시되어 있습니다.

상세 도감도 한국어인가요?

현재 이 페이지는 한국어 입문 허브이며, 상세 도감과 도구는 주로 영어입니다. 각 링크에 언어 상태를 표시했습니다.
