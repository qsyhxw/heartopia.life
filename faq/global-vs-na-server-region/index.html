Quick Answer

If you want to play with friends, choose the same server they use. Region choice matters more than the label itself, because friends, timing, mail, shops, and purchases may not behave the same across server regions.

In player discussions, NA usually means North America or America server. N/A can also mean “not applicable,” so do not read every “n/a” result as a server region.

Heartopia's Chinese name is commonly written as 心动小镇 in simplified Chinese and 心動小鎮 in traditional Chinese.

Server Reset Time: How to Check It

Daily reset is commonly discussed as 6:00 AM server time. Your local reset time depends on which server you chose and whether your local area uses daylight saving time. The most reliable habit is to compare the in-game clock with your local clock.

Simple reset check

  1. Open the in-game watch or time display.
  2. Note the server time shown in game.
  3. Compare it with your phone or computer clock.
  4. Estimate when the server clock reaches 6:00 AM.
  5. Recheck after daylight-saving changes if your local clock shifts.

FAQ

What does Heartopia Global vs N/A mean?⌄

Players usually mean Global vs NA, where NA means North America. If you see N/A with a slash, it may simply mean “not applicable.” Check whether the text is talking about a server, a platform, or a missing value.

What is Heartopia's Chinese name?⌄

The Chinese name is commonly shown as 心动小镇 in simplified Chinese. You may also see 心動小鎮 in traditional Chinese.

Is the China version the same as Global?⌄

Treat it as separate unless the game client itself says otherwise. App store, account, language, payment, event timing, and server access may differ by version or region.

Which server should I pick for codes?⌄

Codes can vary by region, platform, or account status. Use the same region where you actively play, then check the current codes page for claim notes.

Why did my server not reset when I expected?⌄

Most confusion comes from local time vs server time, daylight-saving changes, or being on a different region than expected. Check the in-game clock first, then compare it with your local time.
