Loftia Scrambled Coordinates checks for Ryder

Accept Ryder's Adventure Awaits quest, then harvest resources around Loftia City until you have 3 Scrambled Coordinates. Return to Ryder for the adventure objective.

If harvesting gives no coordinates

  1. Check that Adventure Awaits is active.
  2. Return to Loftia City grass, scrap and clay gathering spots.
  3. Keep gathering useful ordinary materials while waiting for drops.
  4. Return to Ryder when the objective shows three coordinates.

The Early Access quest record ↗ identifies the active-quest gate and city sources. A single empty harvest does not establish that the spot is wrong.

First three versus later supplies

The same record lists a 15-coordinate completion reward and a cost of 3 per adventure. Finish the introductory trip and report back before treating its reward as available. Older Demo objectives may call Ryder the Adventurer.

The developers changed the Daily Goodies Chest so coordinates and Bloom unlock after finishing Ryder's introductory quest. Checking it earlier will not solve the initial objective. Developer patch notes ↗

Follow the current objective

The image illustrates an adventure course. Complete Ryder's current objective before planning repeat trips. For later progression, see the materials checks and Rail Boots unlock.
