Heartopia Call of Whales

A summer Fashionwave season with Whalefall Canyon, Ocean Cleanup, new sea life, and underwater-home content.

Event window

July 11 - August 22

Starts July 11 at 6:00 AM and ends August 22 at 5:59 AM, using server time.

Entry requirement

D.G. Member Level 7

Finish the main story quest “The Answer Lies Within” before looking for the event activity.

Main focus

Sea and Fashionwave

Whalefall Canyon, Ocean Cleanup, the Fashionwave collection, and an underwater home are part of the season.

What is included

Call of Whales content

Whalefall Canyon

The season introduces a new ocean area. Use the live event panel for the current route and available interactions.

Ocean Cleanup

A permanent hobby introduced with the season, separate from the limited event countdown.

Seamount home

The season adds an underwater-home goal alongside the ocean exploration content.

Fashionwave and Memory Journal

Check the in-game event panel for collection progress, shop items, and journal tasks.

Related collection

Sea-life focus

Troubleshooting

If Call of Whales does not appear

The event panel is locked or missing

Confirm your D.G. Member level and main story progress first. Then close and reopen the event panel after the server has refreshed.

The activity is unavailable at your current time

Compare your local clock with server time. The listed end time is 5:59 AM server time, not midnight in every region.

Call of Whales FAQ

When does Call of Whales end?

The event ends on August 22, 2026 at 5:59 AM, using server time.

Is Ocean Cleanup time-limited?

Ocean Cleanup is introduced as a permanent hobby, while the Call of Whales season itself has a limited event window.
