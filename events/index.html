Event FAQ

How do I know an event is active?

Use the in-game event panel and server time. This calendar labels old events separately so their guides are not mistaken for active content.

Why is a past event still listed?

The archive helps with reward names, screenshots, and returning-event history. It does not indicate that an activity is currently open.

Is 711 confirmed as an event?

It is not included in this calendar without an official in-game or publisher announcement.
