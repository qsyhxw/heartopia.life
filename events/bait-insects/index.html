🦋 Bait Insects Event Guide

Two-phase insect catching challenge! Travel from Onsen Mountain to Crater Lake and catch event-exclusive insects!

📋 Event Overview

🔓 Unlock

DG Level 8

📍 Start

Onsen Mountain

⏱️ Duration

7 Minutes

(3 + 1 + 3)

🎯 Hobby

Insect Catching

⚠️ High Stamina Cost!

This event consumes a LOT of stamina. Eat stamina-boosting food before starting!

🎮 Two-Phase Gameplay

PHASE 1 3 Minutes

🏔️ Onsen Mountain

Find the insect baiting device near the lake. Catch as many insects as possible in 3 minutes!

1
→
TRAVEL 1 Minute

🚶 Travel Time

Move from Onsen Mountain to Crater Lake. Use this time to recover stamina!

PHASE 2 3 Minutes

🌋 Crater Lake

Final catching phase at Crater Lake! Different insects spawn here including rare species!

2

🎯 Event Goals

👤

🎁 Rewards: Complete goals to earn Surprise Gacha Pods containing materials, furniture, and exclusive items!

🥅 Catching Mechanics

🎯 How to Catch

  1. 1. Equip bubble net from toolbox
  2. 2. Approach insects slowly (DON'T RUN!)
  3. 3. Tap = quick bubble (close range)
  4. 4. Hold = charged bubble (long range)
  5. 5. Release when close to insect

📈 Hobby Skills

  • • Netting Skill — Increases net range
  • • Insect Quality — Higher ★ catches
  • • Net Maintenance — Better durability
  • • Double Catch — Catch 2 at once!
💡 Tip: Don't run when approaching insects — they'll fly away! Walk slowly for best results.
