Efficient event route

How to run the forest loop

  1. 1. Activate the event quest

    Talk to Naniwa and choose the Frostspore Butterfly dialogue while the season is active.

  2. 2. Start at Forest Lake and Deer Tower

    Sweep the shoreline and flower areas for Sulkowsky's Morpho and Queen Alexandra's Birdwing.

  3. 3. Move south through Spirit-Oak Pine Forest

    Check the jump puzzle and nearby forest for Mother-of-Pearl and Purple Spotted Swallowtail.

  4. 4. Refresh the event insects

    Catch nearby insects instead of waiting at one point. Follow any swarm or event prompt for the Postman Butterfly.

If nothing appears

  • Event inactive: the seasonal entries will not spawn.
  • Quest not started: return to Naniwa and check the event dialogue.
  • Wrong butterfly: regular versions have different levels and locations.
  • Empty route: catch common insects to cycle local spawns, then repeat the loop.
  • Missing Postman: continue the event progression and follow its special spawn prompt.

Frostspore Butterfly FAQ

Can I catch them now?

Not from the ended 2026 season. Wait for an in-game rerun notice before using the route.

Why do some guides list only four?

Four are commonly covered by the normal forest loop. The current database also has the event-specific Frostspore Postman Butterfly.

Does Frostspire mean a different butterfly?

No. Frostspore is the listed spelling; Frostspire and Frostpore are common search variants.

Do weather and time matter?

The five entries list all normal weather and all four time periods. Event availability and quest state matter more.
