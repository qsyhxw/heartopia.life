How to Use This List

  1. Search the dish you need for a quest, collection, or cooking goal.

  3. Open a linked guide when one is available for that dish or ingredient.
  4. Use Learned to keep a personal list in this browser.

Availability Note

Base Game recipes are listed separately from named event collections. An event collection label helps identify where a recipe belongs; access can change when Heartopia updates or returns an event.

Recipe FAQ

How many recipes are listed?
There are 168 entries, including base-game recipes and event collection recipes.

Does this list show ingredients and prices?
Each recipe card shows its listed ingredients, market value tiers, and energy tiers when those fields are available. Use the calculator for your own ingredient-cost planning.

Will my learned marks sync to another device?
No. They are stored only in the browser you are using now.
