Quick Answer

Go to Onsen Mountain and sweep the route with a Bubble Net. Fire-Colored Beetle is flexible because it is listed as all day and works in sunny, rainy, or rainbow weather.

Name note: if you saw "European fireinsect" elsewhere, the current table does not show that exact name. Check Fire-Colored Beetle first, then compare the in-game name against the full insect table.

Onsen Mountain Route

  1. Travel to Onsen Mountain and equip the Bubble Net.
  2. Start with open path edges and rock-side routes where beetles are easier to see.
  3. Because the table lists all-day timing, do not wait for a night-only window.
  4. Any normal sunny, rainy, or rainbow weather can work.
  5. If you find Red-winged Beetle instead, keep sweeping mountain and forest edge spots separately.
