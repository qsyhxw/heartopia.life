💡 Catching Tips

✅ Do

  • • Approach slowly — Insects fly away if you run
  • • Check the weather — Rainbow weather = rare spawns!
  • • Hunt at night — Rare beetles spawn 6PM-6AM
  • • Use Insect Attractor — Spawns special insects
  • • Upgrade Insect Quality skill — Better ★ ratings
