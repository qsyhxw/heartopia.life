How to use this page

Use the listed objective as your in-game checklist. The game can change how it reveals an achievement, so this page groups challenge-style goals instead of claiming a fixed hidden-badge count.

For collection, hobby, dreams, and the rest of the current 63 entries, use the complete achievements list.
