How to Unlock the Drawing Board

  1. 1Reach D.G. Member Level 14.
  2. 2Visit Dorothee at the Clothing Store.
  3. 3Start Jean Morin's Letter.
  4. 4Follow the quest to Ka Ching.
  5. 5Buy the Drawing Board for 2,000 Gold and place it in your home.

What the Drawing Board Opens

Painting interface

Create your own artwork with brushes, colors, eraser-style corrections, stamps, and templates.

Design Gallery

Browse saved designs and community-style inspiration from the Drawing Board menu.

Custom items

Turn designs into clothing or furniture patterns once you have the matching consumable.

Painting Tools and Consumables

Tool Cost / Source Use Important Note
Drawing Board 2,000 Gold from Ka Ching Create paintings, templates, and custom designs. Place it on the ground before trying to open the Gallery.
Paint Can 50 Moonlight Crystals Apply custom designs to compatible furniture. Not every furniture piece accepts custom patterns.
Tailoring Ticket 80 Moonlight Crystals Apply designs to compatible clothing templates. Practice on standard canvas before spending crystals.
Dye 100 Gold or blue bubbles Change basic furniture colors. Dyeing is different from applying a custom pattern.

Custom Clothing Workflow

  1. 1. Make the design: Open the Drawing Board and choose a clothing template.
  2. 2. Keep the design readable: Use bold shapes and simple contrast so it survives the small in-game preview.
  3. 3. Apply with a Ticket: Use a Tailoring Ticket on compatible clothing.
  4. 4. Save a clean version: Keep a copy before recoloring or adding heavy details.

Custom Furniture Workflow

  1. 1. Finish Brushstroke Whimsy: This opens the path toward painted furniture.
  2. 2. Check compatibility: Wooden or joinery-style furniture is the safest target.
  3. 3. Use a Paint Can: Apply the saved design through the furniture customization flow.
  4. 4. Match the room: Repeat a color or motif from your walls, rug, or main decor set.

Which Tool Should You Use?

I want to draw

Use the Drawing Board. This is where the design is created.

I want custom clothes

Use a clothing template, then spend a Tailoring Ticket.

I want custom furniture

Use a saved design and apply it with a Paint Can.

Common Problems

I cannot find Gallery

Place the Drawing Board on the ground and interact with the placed item. Do not look for it only in your inventory.

The board is not in the shop

Check that you are DG Level 14 and have started Dorothee's painting questline.

Furniture will not accept my design

Use a different furniture piece. Some items can be dyed but cannot use custom patterns.

Painting Tools FAQ

Is there a Heartopia painting tool website?

This page now includes a browser-based pixel planner for preparing references. The final design still needs to be recreated or adjusted inside Heartopia's in-game Drawing Board and Gallery flow.

What is the difference between Paint Can and Dye?

Dye changes a basic color. Paint Can applies one of your custom designs to compatible furniture.

Do I need the Drawing Board for clothing designs?

Yes. The Drawing Board is where you create or edit the design before applying it with a Tailoring Ticket.

Where should I go next?

Use the Gallery guide if you are stuck on View Gallery, or the Decoration guide for room layout and dyeing tips.
